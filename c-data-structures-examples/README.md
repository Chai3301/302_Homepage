## 各データ構造の概要

### 01. 動的配列 (Dynamic Array)
- サイズが自動的に拡張される配列
- `malloc`, `realloc`, `free` の使い方を学ぶ
- std::vector (C++) や ArrayList (Java) の基礎

### 02. 単方向連結リスト (Singly Linked List)
- ノードがnextポインタで連結された構造
- 挿入・削除がO(1)で可能
- リストの走査と反転

### 03. 双方向連結リスト (Doubly Linked List)
- 前後両方向のポインタを持つリスト
- 両端からの操作が効率的
- より複雑なポインタ操作

### 04. スタック (Stack)
- LIFO (Last In, First Out) 構造
- 配列ベースと連結リストベースの2種類を実装
- 実用例: 括弧の対応チェック

### 05. キュー (Queue)
- FIFO (First In, First Out) 構造
- 循環配列による効率的な実装
- 連結リストベースの実装

### 06. 二分探索木 (Binary Search Tree)
- 左の子 < 親 < 右の子 の関係を持つ木
- 探索・挿入・削除がO(log n)
- 3種類の走査: 前順、中順、後順

### 07. ハッシュテーブル (Hash Table)
- キーと値のペアを格納
- O(1)の平均検索時間
- チェイン法による衝突解決

### 08. ヒープ (Heap)
- 完全二分木を配列で表現
- 最小/最大値の取得がO(1)
- ヒープソートの実装

### 09. グラフ (Graph)
- 頂点と辺からなる構造
- 隣接リストによる表現
- DFS、BFS、最短経路探索

### 10. 循環バッファ (Circular Buffer)
- 固定サイズの効率的なバッファ
- ストリーミングデータやログに最適
- オーバーフロー時の上書きオプション

## 学習の進め方

1. **基礎から始める**: 01〜04は基本的なポインタ操作を学べます
2. **コードを読む**: 各ファイルには詳細なコメントがあります
3. **動かしてみる**: コンパイルして実行し、出力を確認しましょう
4. **改造してみる**: 機能を追加したり、別の方法で実装してみましょう
5. **デバッグする**: gdbやprintfを使って内部動作を追いかけてみましょう
